# Команды Linux

Мой справочник. Пополняется после каждого урока.

## Навигация (урок 1)

| Команда | Что делает | Пример | Осторожно |
|---|---|---|---|
| `pwd` | показывает, где я стою | `pwd` | спрашивать перед любым действием |
| `ls` | что лежит в текущей папке | `ls` | скрытое не показывает |
| `ls папка` | что лежит в другой папке, не заходя | `ls Desktop` | |
| `ls -la` | подробно и со скрытым | `ls -la` | размер в байтах, права, владелец |
| `cd папка` | зайти в папку | `cd Desktop` | в Linux регистр важен: `Desktop` не равно `desktop` |
| `cd ..` | подняться на уровень вверх | `cd ..` | |
| `cd ~` | вернуться домой | `cd ~` | `~` это `/home/имя` в Linux |
| `cd путь/путь` | зайти сразу глубоко | `cd ~/Desktop/systems-path` | |

## Файлы (урок 2)

| Команда | Что делает | Пример | Осторожно |
|---|---|---|---|
| `mkdir имя` | создать папку | `mkdir sandbox` | |
| `touch файл` | создать пустой файл | `touch notes.txt` | опечатка в имени создаст другой файл |
| `echo "текст"` | напечатать текст | `echo "привет"` | |
| `cat файл` | показать содержимое файла | `cat notes.txt` | |
| `echo "текст" > файл` | записать в файл | `echo "a" > notes.txt` | **стирает** всё старое |
| `echo "текст" >> файл` | дописать в конец файла | `echo "b" >> notes.txt` | старое остаётся |
| `cp что куда` | скопировать | `cp notes.txt backup.txt` | оригинал остаётся |
| `mv что куда` | переместить или переименовать | `mv backup.txt old.txt` | оригинала больше нет |
| `rm файл` | удалить | `rm old.txt` | навсегда, без корзины; сначала `ls` |

## Знаки

| Знак | Значение |
|---|---|
| `/` | корень системы, разделитель папок в пути |
| `~` | моя домашняя папка |
| `.` | эта папка |
| `..` | папка выше |
| `>` | вывести в файл, стерев старое |
| `>>` | дописать в файл |
| `-la` | флаги: буквы, которые меняют поведение команды |
