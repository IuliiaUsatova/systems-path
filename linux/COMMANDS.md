# Команды Linux

Мой справочник. Пополняется после каждого урока.

## Навигация (урок 1)

| Команда | Что делает | Пример | Осторожно |
|---|---|---|---|
| `pwd` | показывает, где я стою | `pwd` | спрашивать перед любым действием |
| `ls` | что лежит в текущей папке | `ls` | скрытое не показывает |
| `ls папка` | что лежит в другой папке, не заходя | `ls Desktop` | |
| `ls -la` | подробно и со скрытым | `ls -la` | размер в байтах, права, владелец |
| `cd папка` | зайти в папку | `cd Desktop` | в Linux регистр важен: `Desktop` не равно `desktop` |
| `cd ..` | подняться на уровень вверх | `cd ..` | |
| `cd ~` | вернуться домой | `cd ~` | `~` это `/home/имя` в Linux |
| `cd путь/путь` | зайти сразу глубоко | `cd ~/Desktop/systems-path` | |

## Файлы (урок 2)

| Команда | Что делает | Пример | Осторожно |
|---|---|---|---|
| `mkdir имя` | создать папку | `mkdir sandbox` | |
| `touch файл` | создать пустой файл | `touch notes.txt` | опечатка в имени создаст другой файл |
| `echo "текст"` | напечатать текст | `echo "привет"` | |
| `cat файл` | показать содержимое файла | `cat notes.txt` | |
| `echo "текст" > файл` | записать в файл | `echo "a" > notes.txt` | **стирает** всё старое |
| `echo "текст" >> файл` | дописать в конец файла | `echo "b" >> notes.txt` | старое остаётся |
| `cp что куда` | скопировать | `cp notes.txt backup.txt` | оригинал остаётся |
| `mv что куда` | переместить или переименовать | `mv backup.txt old.txt` | оригинала больше нет |
| `rm файл` | удалить | `rm old.txt` | навсегда, без корзины; сначала `ls` |

## Знаки

| Знак | Значение |
|---|---|
| `/` | корень системы, разделитель папок в пути |
| `~` | моя домашняя папка |
| `.` | эта папка |
| `..` | папка выше |
| `>` | вывести в файл, стерев старое |
| `>>` | дописать в файл |
| `-la` | флаги: буквы, которые меняют поведение команды |


## Читать и искать (урок 3)

| Команда | Что делает | Пример | Осторожно |
|---|---|---|---|
| `less файл` | читать по страницам | `less /etc/services` | выход `q` |
| `grep слово файл` | строки, где есть слово | `grep ssh /etc/services` | ищет подстроку где угодно |
| `grep -i` | без учёта регистра | `grep -i SSH файл` | |
| `grep -c` | посчитать строки | `grep -c ssh файл` | |
| `grep -r` | искать в папке целиком | `grep -r rocketfirm linux` | |
| `cmd1 \| cmd2` | вывод слева отдать команде справа | `ls \| grep .md` | можно цепочкой |
| `wc -l` | посчитать строки | `ls \| wc -l` | |
| `nano файл` | редактор в терминале | `nano config.txt` | `Ctrl+O` сохранить, `Ctrl+X` выйти |

| Команда | Что делает | Пример | Осторожно |
|---|---|---|---|
| `ssh root@IP` | войти на сервер | `ssh root@IP_сервера` | первый раз спросит про отпечаток |

| `uptime` | сколько работает, нагрузка за 1/5/15 мин | | для 1 ядра 1.0 = занят полностью |

## SSH-сервер и файрвол (урок 7)

| Команда | Что делает | Пример | Осторожно |
|---|---|---|---|
| `ps aux \| grep sshd` | кто подключён к серверу | | последняя строка это сам grep |
| `sshd -T` | итоговые настройки ssh-сервера | `sudo sshd -T \| grep -i permitrootlogin` | большая T |
| `sshd -t` | проверить конфиг на опечатки | `sudo sshd -t` | маленькая t, пусто значит ок |
| `grep -n` | поиск с номерами строк | `grep -n "PermitRootLogin" /etc/ssh/sshd_config` | |
| `grep "a\|b"` | искать a или b | | |
| `grep "^слово"` | строки, которые начинаются со слова | | отсекает комментарии |
| `head -15 файл` | начало файла | `head -15 /etc/ssh/sshd_config` | искать Include |
| `nano` + `Ctrl+_` | перейти на строку по номеру | | |
| `systemctl restart ssh` | перезапустить ssh-сервер | `sudo systemctl restart ssh` | сначала `sshd -t` |
| `systemctl status имя` | работает ли служба | `systemctl status ssh` | выход q |
| `ssh -o PubkeyAuthentication=no` | попытка входа без ключа | `ssh -o PubkeyAuthentication=no user@IP_сервера` | должен отказать |
| `ufw status` | состояние файрвола и правила | `sudo ufw status` | |
| `ufw allow порт` | открыть порт | `sudo ufw allow 22` | до enable |
| `ufw enable` | включить файрвол | `sudo ufw enable` | только после allow 22 |
| `ufw delete allow порт` | убрать правило | `sudo ufw delete allow 80` | |
| `apt list --installed` | что установлено | `apt list --installed \| grep nginx` | |

Порядок правки ssh-сервера: два окна → nano → `sshd -t` → `restart` → `sshd -T` → вход из нового окна.
