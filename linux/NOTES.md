## Урок 1. Где я и что вокруг

### Терминал всегда где-то стоит

У терминала всегда есть текущая папка, как у Finder всегда открыта какая-то папка.
Окна нет, поэтому, чтобы узнать, где я, надо спросить командой `pwd`.

Правило: перед любым действием спроси `pwd`.
Мой репозиторий `systems-path` оказался на рабочем столе, а не дома,
потому что во время `git clone` терминал стоял не там, где я думала.

### Пути

Путь читается слева направо, папки разделяются `/`.

- `/` в самом начале это корень, верхняя папка всего компьютера.
- `/Users/Iuliia/Desktop` значит: из корня в Users, оттуда в Iuliia, оттуда в Desktop.
- `~` это короткая запись домашней папки.

| Система | Домашняя папка |
|---|---|
| macOS | /Users/имя |
| Linux | /home/имя |

Особые имена:

| Имя | Что значит |
|---|---|
| `.` | эта папка, где я стою |
| `..` | папка уровнем выше (родитель) |
| `~` | моя домашняя папка |

### Команды урока

| Команда | Расшифровка | Что делает |
|---|---|---|
| `pwd` | print working directory | показывает, где я стою |
| `ls` | list | показывает, что лежит в текущей папке |
| `ls Папка` | list | показывает содержимое другой папки, не заходя в неё |
| `ls -la` | list, long, all | подробный список, включая скрытое |
| `cd Папка` | change directory | зайти в папку |
| `cd ..` | | подняться на одну папку вверх |
| `cd ~` | | вернуться домой |

`ls -la` это два флага сразу: `-l` (подробно) и `-a` (всё, включая скрытое).

### Скрытые файлы

Всё, что начинается с точки, скрыто: обычный `ls` его не показывает, `ls -la` показывает.
Пример: `.git` это скрытая папка, в которой git хранит всю историю репозитория.
Удалить её значит превратить репозиторий в обычную папку.

### Как читать строку `ls -la`

Пример:

    -rw-r--r--  1  Iuliia  staff  443  Oct 28 01:24  README.md

| Часть | Пример | Что значит |
|---|---|---|
| первый символ | `-` | `-` файл, `d` папка (directory) |
| права | `rw-r--r--` | кто может читать (r), писать (w), запускать (x) |
| владелец | `Iuliia` | чей файл |
| группа | `staff` | группа пользователей |
| размер | `443` | размер в байтах |
| дата | `Oct 28 01:24` | когда менялся |
| имя | `README.md` | имя файла |

Связь с модулем 1: 443 байта это 3544 бита. А права `rwx` это три бита на каждую группу
(владелец, группа, остальные): читать да/нет, писать да/нет, запускать да/нет.

### Ловушка: регистр букв

macOS не различает большие и маленькие буквы в именах, Linux различает.
Я набрала `cd desktop`, и Мак пустил в `Desktop`.
На сервере `desktop` и `Desktop` это две разные папки, и одной из них может не быть.
